## Agent skills

### Issue tracker

Issues and specs live as GitHub issues; use the `gh` CLI for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage roles as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Read `CONTEXT.md` and `docs/adr/` before exploring the codebase (single-context layout). See `docs/agents/domain.md`.
